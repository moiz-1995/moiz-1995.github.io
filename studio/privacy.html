Privacy policy

Kids Studio · last updated 23 November 2026

Who uses it

Kids Studio is a private tool used only by its owner, Agha Abdul Moiz, to publish videos to his own YouTube channels. It is not offered to the public.

What data it accesses

When the owner signs in with Google, Kids Studio receives permission to upload and manage videos on the owner's YouTube channels and to read those videos' details and view counts. It does not access email, contacts, files or any other Google data, and it never accesses any other person's account.

How the data is used and stored

The sign-in token is stored only on the owner's own computer and is used only to publish and check the owner's own videos. No data is sold, shared with third parties, used for advertising, or used to train AI models.

Google API Services

Kids Studio's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the token file on the owner's computer also ends it.
